# 🎮 Jogo de Plataforma — Versão Terror

Um jogo de plataforma inspirado nos clássicos jogos no estilo Mario, mas com uma proposta totalmente diferente e uma estética voltada para o **terror**.

Desenvolvido como um projeto para praticar desenvolvimento web, o jogo utiliza **HTML, CSS e JavaScript** para criar as mecânicas, interações e identidade visual da aplicação.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- 🎮 Movimentação do personagem
- 🏃 Mecânicas de plataforma
- 💥 Sistema de colisão
- 🖱️ Interações e eventos com JavaScript
- 🌑 Ambientação inspirada no terror
- 🎨 Elementos visuais personalizados

## 📚 Sobre o projeto

Neste projeto, desenvolvi uma versão própria de um jogo de plataforma inspirada nos clássicos jogos do gênero, mas trazendo uma **identidade visual voltada para o terror**.

A ideia surgiu como uma forma de combinar dois interesses: **programação e criatividade**. Em vez de reproduzir o estilo tradicional dos jogos de plataforma, adaptei a proposta para uma atmosfera mais sombria.

## 🧠 O que pratiquei

Durante o desenvolvimento, pude praticar conceitos como:

- Manipulação de elementos da página
- Movimentação de personagens
- Lógica de colisão
- Eventos em JavaScript
- Interatividade com o usuário
- Organização do código
- Estruturação de páginas com HTML
- Estilização e ambientação com CSS

## 🎯 Objetivo

Praticar conceitos de **HTML, CSS e JavaScript** por meio da criação de um projeto interativo, explorando também a utilização da programação para transformar uma ideia criativa em uma experiência jogável.

## 🎨 Criatividade e desenvolvimento

Além da parte técnica, este projeto foi uma oportunidade de experimentar diferentes elementos visuais e criar uma identidade própria para o jogo.

A proposta de transformar um conceito conhecido em uma versão de terror também me permitiu explorar como **programação e criatividade podem trabalhar juntas** na criação de projetos.

## 🚀 Aprendizado

Este projeto faz parte da minha evolução no desenvolvimento web e foi uma oportunidade de colocar em prática conceitos de JavaScript de uma maneira mais interativa.

Continuo desenvolvendo novos projetos para aprimorar meus conhecimentos e explorar diferentes possibilidades dentro da programação.
